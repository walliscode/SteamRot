### 1.2 Implement CaptureSnapshot

**File:** `tests/harness/TestEngine.cpp`

**Add implementation:**
```cpp
/////////////////////////////////////////////////
void TestEngine::CaptureSnapshot(size_t tick) {
  EngineSnapshot snapshot;
  
  // Get all scenes from SceneManager
  const auto& scenes = m_scene_manager.GetScenes();
  
  // Capture EntityMemoryPool for each active scene
  for (const auto& [scene_uuid, scene_ptr] : scenes) {
    if (scene_ptr && scene_ptr->GetActive()) {
      // Get the EntityMemoryPool from the scene
      const EntityMemoryPool& scene_pool = scene_ptr->GetEntityMemoryPool();
      
      // Deep copy the pool into the snapshot with scene UUID as key
      snapshot.scene_snapshots[scene_uuid] = scene_pool;
    }
  }
  
  // Store the complete snapshot in the data bank
  m_data_bank[tick] = std::move(snapshot);
}
```

**Note:** If `Scene` doesn't have `GetEntityMemoryPool()`, you may need to add it or access it through `SceneContext`.

## Phase 2: Snapshot Capture Integration

### 2.1 Verify Scene Access

Ensure TestEngine can access the scene's EntityMemoryPool:

**Option A:** Scene has direct getter
```cpp
class Scene {
public:
  const EntityMemoryPool& GetEntityMemoryPool() const {
    return m_scene_context.scene_entities;
  }
};
```

**Option B:** Access through SceneManager
```cpp
const auto& scene_context = m_scene_manager.GetCurrentScene().GetSceneContext();
const EntityMemoryPool& scene_pool = scene_context.scene_entities;
```

**Option C:** SceneManager provides direct access
```cpp
const EntityMemoryPool& scene_pool = m_scene_manager.GetCurrentSceneEntityPool();
```

Choose the option that fits the existing architecture.

### 2.2 Multi-Scene Support Architecture

The implementation supports multiple scenes per tick from the start using scene UUIDs:

**Key Design Decisions:**

1. **Scene Identification:** Uses `uuids::uuid` (already used by SceneManager)
   - UUIDs are generated by the engine at runtime when scenes are created
   - Provides unique identification across scene types and instances

2. **Data Structure:** `EngineSnapshot` contains `std::unordered_map<uuids::uuid, EntityMemoryPool>`
   - Maps scene UUID to its EntityMemoryPool state
   - Supports any number of active scenes per tick
   - Empty map if no scenes are active

3. **Scene UUID Mapping in TestData:**
   - Test data specifies expected state per scene by SceneType (e.g., "TitleScene")
   - TestEngine generates UUIDs when creating scenes from TestData
   - Comparison logic matches by SceneType first, then compares EntityMemoryPool

**Implementation Note:** The UUID approach is not overcomplicating - it's the natural fit because:
- SceneManager already uses UUIDs as the primary scene identifier
- Multiple instances of the same SceneType may exist (e.g., multiple inventory scenes)
- UUIDs provide stable identifiers across test execution

**Example Snapshot Structure:**
```cpp
// Tick 0 with 2 active scenes
m_data_bank[0] = EngineSnapshot{
  .scene_snapshots = {
    {uuid_1, EntityMemoryPool_TitleScene},
    {uuid_2, EntityMemoryPool_InventoryScene}
  }
};
```

```cpp
std::expected<std::monostate, FailInfo> CompareEngineSnapshot(
    size_t tick,
    const EngineSnapshot& actual_snapshot,
    const EngineSnapshot& expected_snapshot,
    const TestContext& test_context) {
  
  // First, check that we have the same number of scenes
  if (actual_snapshot.scene_snapshots.size() != 
      expected_snapshot.scene_snapshots.size()) {
    return std::unexpected(FailInfo{
        FailMode::ValidationFailed,
        std::format("Scene count mismatch at tick {}: actual={}, expected={}", 
                   tick, 
                   actual_snapshot.scene_snapshots.size(),
                   expected_snapshot.scene_snapshots.size())
    });
  }
  
  // Compare each scene's EntityMemoryPool
  // Note: This assumes expected_snapshot uses the same UUIDs generated by TestEngine
  // In practice, TestData may need to map by SceneType or provide UUID mapping
  for (const auto& [expected_uuid, expected_pool] : expected_snapshot.scene_snapshots) {
    auto it = actual_snapshot.scene_snapshots.find(expected_uuid);
    if (it == actual_snapshot.scene_snapshots.end()) {
      return std::unexpected(FailInfo{
          FailMode::ValidationFailed,
          std::format("Scene UUID {} not found in actual snapshot at tick {}", 
                     uuids::to_string(expected_uuid), tick)
      });
    }
    
    const EntityMemoryPool& actual_pool = it->second;
    
    // Create matcher with test context
    EntityMemoryPoolEqualsMatcher matcher(expected_pool, test_context);
    
    // Perform comparison
    if (!matcher.match(actual_pool)) {
      return std::unexpected(FailInfo{
          FailMode::ValidationFailed,
          std::format("Scene {} comparison failed at tick {}\n{}", 
                     uuids::to_string(expected_uuid), tick, matcher.describe())
      });
    }
  }
  
  return std::monostate{};
}
```

**Note:** The comparison logic above assumes exact UUID matching. In practice, you may want to:
1. Match scenes by SceneType instead of UUID
2. Provide a UUID mapping in TestData that gets populated by TestEngine
3. Use a more flexible matching strategy for multi-instance scenarios
```

### 3.2 Update RunTestEngineTest Function

**File:** `tests/harness/test_harness.cpp` (or wherever this function lives)

```cpp
std::expected<std::monostate, FailInfo> 
RunTestEngineTest(const TestDataConfig* config) {
  // Validate config
  if (!config || !config->metadata()) {
    return std::unexpected(FailInfo{
        FailMode::InvalidInput,
        "TestDataConfig or metadata is null"
    });
  }
  
  // Convert FlatBuffers TestDataConfig to TestData
  // (Implementation depends on existing conversion functions)
  TestData test_data = ConvertTestDataConfigToTestData(config);
  
  // Create and run TestEngine
  TestEngine engine(test_data);
  auto run_result = engine.RunGame();
  if (!run_result.has_value()) {
    return std::unexpected(run_result.error());
  }
  
  // Get data bank
  const auto& data_bank = engine.GetDataBank();
  
  // Prepare test context
  TestContext base_context;
  base_context.test_name = config->metadata()->test_name()->str();
  base_context.description = config->metadata()->description()->str();
  base_context.total_ticks = test_data.number_of_ticks;
  
  // Compare each expected snapshot
  for (const auto& [tick, expected_snapshot] : test_data.expected_engine_snapshots) {
    // Find actual snapshot in data bank
    auto it = data_bank.find(tick);
    if (it == data_bank.end()) {
      return std::unexpected(FailInfo{
          FailMode::MissingData,
          std::format("No snapshot found in data bank for tick {}", tick)
      });
    }
    
    const EngineSnapshot& actual_snapshot = it->second;
    
    // Update context with current tick
    TestContext tick_context = base_context;
    tick_context.current_tick = tick;
    
    // Compare using helper function
    auto compare_result = CompareEngineSnapshot(
        tick, actual_snapshot, expected_snapshot, tick_context);
    
    if (!compare_result.has_value()) {
      return std::unexpected(compare_result.error());
    }
  }
  
  return std::monostate{};
}
```

std::expected<std::monostate, FailInfo> CompareEngineSnapshot(
    size_t tick,
    const EngineSnapshot& actual,
    const EngineSnapshot& expected,
    const TestContext& test_context) {
  
  // Compare scene count
  if (actual.scene_snapshots.size() != expected.scene_snapshots.size()) {
    return std::unexpected(FailInfo{
        FailMode::ValidationFailed,
        std::format("Scene count mismatch at tick {}: actual={}, expected={}", 
                   tick, actual.scene_snapshots.size(), expected.scene_snapshots.size())
    });
  }
  
  // Compare each scene's EntityMemoryPool
  for (const auto& [expected_uuid, expected_pool] : expected.scene_snapshots) {
    auto it = actual.scene_snapshots.find(expected_uuid);
    if (it == actual.scene_snapshots.end()) {
      return std::unexpected(FailInfo{
          FailMode::ValidationFailed,
          std::format("Scene UUID {} not found at tick {}", 
                     uuids::to_string(expected_uuid), tick)
      });
    }
    
    const EntityMemoryPool& actual_pool = it->second;
    EntityMemoryPoolEqualsMatcher pool_matcher(expected_pool, test_context);
    if (!pool_matcher.match(actual_pool)) {
      return std::unexpected(FailInfo{
          FailMode::ValidationFailed,
          std::format("Scene {} entity pool mismatch at tick {}\n{}", 
                     uuids::to_string(expected_uuid), tick, pool_matcher.describe())
      });
    }
  }
  
  // Compare EventBus (if present in expected snapshot) - NEW
  if (expected.event_bus.has_value()) {
    EventBusEqualsMatcher bus_matcher(expected.event_bus.value(), test_context);
    if (!bus_matcher.match(actual.event_bus.value())) {
      return std::unexpected(FailInfo{
          FailMode::ValidationFailed,
          std::format("Event bus mismatch at tick {}\n{}", 
                     tick, bus_matcher.describe())
      });
    }
  }
  
  return std::monostate{};
}

## Common Issues and Solutions

### Issue 1: Scene doesn't expose EntityMemoryPool

**Solution:** Add getter to Scene class
```cpp
// In Scene.h
class Scene {
public:
  const EntityMemoryPool& GetEntityMemoryPool() const {
    return m_scene_context.scene_entities;
  }
};
```

### Issue 2: Copying EntityMemoryPool is slow

**Solution:** Profile first, optimize only if needed
```cpp
// Measure copy time
auto start = std::chrono::high_resolution_clock::now();
m_data_bank[tick] = scene_pool;
auto end = std::chrono::high_resolution_clock::now();
auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
if (duration.count() > 1000) {
  spdlog::warn("Slow snapshot copy: {} μs", duration.count());
}
```

**Optimization:** Use move semantics if possible (rarely needed)

### Issue 3: TestData doesn't have expected_engine_snapshots

**Solution:** Add to TestData struct if missing
```cpp
// In TestData.h
struct TestData {
  // ... existing fields ...
  std::map<size_t, EngineSnapshot> expected_engine_snapshots;
};
```

### Issue 4: Comparison fails with unclear errors

**Solution:** Ensure TestContext is populated
```cpp
TestContext context;
context.test_name = "my_test";
context.current_tick = tick;
context.total_ticks = total;
// Context is included in matcher output
```

## Performance Targets

### Snapshot Capture
- **Target:** < 100 μs per snapshot for typical test (50 entities)
- **Acceptable:** < 1 ms per snapshot for stress test (1000 entities)
- **If exceeded:** Profile and optimize (unlikely to be needed)

### Memory Usage
- **Target:** < 1 MB for typical test (5 ticks, 50 entities)
- **Acceptable:** < 100 MB for stress test (100 ticks, 1000 entities)
- **If exceeded:** Consider selective snapshotting (capture only expected ticks)
