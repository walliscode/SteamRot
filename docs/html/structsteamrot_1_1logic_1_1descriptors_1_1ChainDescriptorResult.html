Detailed Description

Result type for ChainDescriptor evaluations.

valid_subgraph records the first matching part-ID path and invalid_subgraphs records rejected part-ID paths explored by the DFS. The m_trace (inherited from DescriptorResult) contains the full structured event sequence and is the primary source for analysis output.
