Detailed Description

Contains all data necessary to create a MachinaForm.

3struct MachinaFormScaffold

This is designed to be an "unbaked" editor workspace. When committed to a MachinaForm, the scaffold data will be processed into efficient runtime formats by the MachinaForm's own systems.
