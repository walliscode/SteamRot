Process all active ROTATE_GHOST subscribers and rotate the ghost.

Iterates subscribers; for each active subscriber whose captured_payload holds an InputPayload with action ROTATE_GHOST, calls RotateGhost once. This function is the authoritative place for subscriber-driven rotation logic and is intended to be called from GhostPositioningLogic::ProcessLogic().

Parameters
subscribersSubscribers owned by the calling Logic instance.
mr_ghostMrGhost instance whose rotation will be updated.

Update the world-space position of MrGhost to match the current mouse cursor, and cache the result in world_mouse_position.

Converts the screen-space mouse position to world-space coordinates using positioning::camera::MapToWorldCoords (the single authoritative conversion), writes the result into both world_mouse_position and mr_ghost.m_position, and should be called once per tick before any world-space system consumes either value. The stored mr_ghost.m_rotation_degrees is applied to the instance transform so the ghost is rendered at the correct rotation.

Parameters
mr_ghostMrGhost instance whose position will be updated.
world_mouse_positionOut-parameter receiving the computed world-space cursor position (stored in SceneResources and exposed via SceneContext::world_mouse_position).
mouse_positionScreen-space pixel position of the mouse cursor.
camera_stateCamera/view state used for the coordinate conversion.
scene_textureRender texture required by MapToWorldCoords.
