Detailed Description

Procedural description of a Joint's socket layout.

Sockets are distributed evenly within the arc [arc_min, arc_max] at the given radius from the Joint's local origin. When arc_max - arc_min equals 360 degrees (a full circle), sockets are placed at equal angular intervals with no duplicate at the wrap-around point.

An optional fixed anchor socket (socket index 0 when has_fixed_socket is true) sits at fixed_socket_angle and is excluded from current_rotation. Remaining sockets rotate with the ring.
