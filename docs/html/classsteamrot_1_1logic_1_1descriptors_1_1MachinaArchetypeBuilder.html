Detailed Description

template<typename T>
class steamrot::logic::descriptors::MachinaArchetypeBuilder< T >

Fluent builder that assembles a MachinaArchetype from an ordered list of ChainDescriptor steps.

Template Parameters
TUser-defined result struct whose member fields receive the SubGraph produced by each step. Each Then() call binds one ChainDescriptor to one SubGraph member of T.

Typical usage:

struct GrabArchetype { SubGraph arm; SubGraph grip; };
MachinaArchetype archetype =
MachinaArchetypeBuilder<GrabArchetype>{}
.Then(is_serial_arm, &GrabArchetype::arm)
.Then(is_grip, &GrabArchetype::grip)
.Build("grab");

Consume the builder and produce a named MachinaArchetype.

The returned MachinaArchetype wraps a lambda that, when called with a (PartGraph, part_id) pair, evaluates every accumulated step in order. The overall result is true only when all steps succeed.
