Detailed Description

Named, callable predicate for a multi-hop walk from one anchor node.

Wraps a std::function with the signature ChainDescriptorResult(const PartGraph&, uint32_t part_id). A ChainDescriptor answers a structural question about a subgraph reachable from the start node (e.g. "does a 3-node linear chain begin here?") rather than a question about the start node alone.

Build instances with steamrot::logic::descriptors::ChainDescriptorBuilder (see ChainDescriptorBuilder.h).
