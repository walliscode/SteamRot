Detailed Description

Scene runtime state.

SceneState contains runtime operational data that changes during scene execution. This includes execution control flags and performance tracking. Unlike SceneConfig, this state is mutable and changes frequently during runtime.

State flag indicating whether the mouse is currently over any UI layer in the scene.

This flag is set by UICollisionLogic during mouse collision checks and can be used by other logic to conditionally disable non-UI interactions when the mouse is over the UI.
