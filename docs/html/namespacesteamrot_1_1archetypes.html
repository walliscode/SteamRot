Returns entity indexes sorted by m_priority of the given Component.

The Component type must have an integer m_priority member field. Entities with equal priority retain their original index order.

Template Parameters
ComponentComponent type with an m_priority field.
Parameters
archetypesArchetype map to search.
entity_memory_poolPool used to read component priority values.
ascendingWhen true, returns lowest priority first (for rendering). When false, returns highest priority first (for collision).
Returns
Sorted vector of entity indexes.
