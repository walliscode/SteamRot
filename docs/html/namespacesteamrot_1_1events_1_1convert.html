bool steamrot::events::convert::CollectGhostClearEvents ( const std::vector< sf::Event > & sfml_events)

Detect a ghost-clear request from SFML events (Q key press).

Checks for sf::Event::KeyPressed with the Q key. A Q press signals that the user wants to clear the current ghost selection.

Parameters
sfml_eventsVector of SFML events gathered this tick.
Returns
true if a ghost-clear-triggering event was found, false otherwise.

Collect keyboard and mouse SFML events into a UserInputBitset.

◆ CollectPanEvents()

std::vector< CameraPayload > steamrot::events::convert::CollectPanEvents ( const std::vector< sf::Event > & sfml_events)

Collect WASD key-press and key-release events as CameraPayloads.

Iterates the SFML events and emits one CameraPayload per W/A/S/D key-press (PAN_PRESS) or key-release (PAN_RELEASE). Returns an empty vector when no WASD events occurred this tick.

Parameters
sfml_eventsVector of SFML events gathered this tick.
Returns
Zero or more CameraPayloads representing pan press/release events.

bool steamrot::events::convert::CollectSystemEvents ( const std::vector< sf::Event > & sfml_events)

Collect system-level SFML events (window close and Escape key).

Checks for sf::Event::Closed and sf::Event::KeyPressed with the Escape key. Either of these signals that the user wants to quit the application.

Parameters
sfml_eventsVector of SFML events gathered this tick.
Returns
true if a QUIT-triggering event was found, false otherwise.

Resolve an InputAction from a bitset using the registry.

Each registry entry is checked to see whether its required bits are all set in accumulated. The first matching entry wins.

Parameters

registryRegistry of (pattern → action) mappings.
Returns
The matched InputAction, or std::nullopt when nothing matches.
