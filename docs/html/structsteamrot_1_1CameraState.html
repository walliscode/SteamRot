Detailed Description

Holds the per-scene camera/view state.

Pure data container. All view computation and zoom/pan mutations are performed by free functions in steamrot::logic::positioning::camera.

◆ m_zoom_level

float steamrot::CameraState::m_zoom_level {1.0f}

Current zoom level.

A value of 1.0 is the default (no zoom). Values > 1.0 zoom out (more world visible); values < 1.0 zoom in (less world visible).
