Detailed Description

Bundles the local position and mutable runtime state for a single socket on a placed part instance.

local_position is initialised at construction from the owning Part definition and may be updated by positioning Logic (e.g. to rotate the socket ring of a JointInstance). state holds the mutable connection status and hover flag that are updated each tick by Logic.

Local-space position of this socket.

◆ proximity_scale

std::optional<uint8_t> steamrot::SocketData::proximity_scale {std::nullopt}

Proximity brightness scale in the range [0, 255].

Set when is_another_socket_near is true. The value maps the distance to the nearest socket onto a [0, 255] range: 255 at the connection threshold (closest) and 0 at the outer proximity threshold (furthest within range). Reset to std::nullopt by the collision system whenever is_another_socket_near is false.
