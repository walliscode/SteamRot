Detailed Description

Named, callable predicate for single-node queries on a PartGraph.

Wraps a std::function with the signature NodeDescriptorResult(const PartGraph&, uint32_t part_id) and a stable string name used in analysis traces.

operator() calls the underlying function and records NodeEval and NodeResult trace events in the returned result.

Example:

NodeDescriptorResult result = descriptors::is_fragment(scaffold.parts, id);
if (result) { /* node is a fragment */ }

Evaluate the predicate and record trace events.

Emits a NodeEval event before and a NodeResult event after calling the underlying function. Both events carry depth so that callers (e.g. the DFS in ChainDescriptorBuilder) can control nesting.
