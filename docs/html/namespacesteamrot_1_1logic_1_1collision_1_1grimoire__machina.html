Check for collisions between a FragmentInstance's sockets and every JointInstance in the PartGraph, keeping only the most-proximal candidate per socket.

Resets all proximity state on both the fragment_instance sockets and all PartGraph sockets before iterating, so that each call produces a clean result independent of any prior state. Only Fragment–Joint pairs are evaluated; Fragment–Fragment collisions are not checked here.

void steamrot::logic::collision::grimoire_machina::check_socket_collisions ( SocketData & socket_data,
const sf::Transform & socket_transform,
SocketData & other_socket_data,

Check for a collision between two individual sockets, writing state only when the measured distance is strictly smaller than the best candidate already recorded on each socket.

Both sockets are updated symmetrically. If the distance between the two world-space socket positions is within the connection threshold, is_ready_to_connect is set; if it is within the proximity threshold but outside the connection threshold, is_another_socket_near is set. In either case the state is written only when this pair is closer than the current distance_to_nearest_socket on the respective socket, ensuring that the most-proximal candidate always wins across multiple pairs.

Parameters
socket_dataSocketData for the first socket.
socket_transformWorld-space transform of the first socket's owning PartInstance.
other_socket_dataSocketData for the second socket.
other_socket_transformWorld-space transform of the second socket's owning PartInstance.

void steamrot::logic::collision::grimoire_machina::reset_socket_proximity_state ( PartGraph & part_graph)

Reset proximity state on every socket in the PartGraph.

Clears is_another_socket_near, is_ready_to_connect, and distance_to_nearest_socket on all sockets of every part in part_graph. Must be called at the start of each full collision pass so that stale state from the previous tick does not bleed into the new results.

Parameters
part_graphPartGraph whose socket proximity state should be cleared.
