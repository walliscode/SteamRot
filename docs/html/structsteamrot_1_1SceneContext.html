Detailed Description

Lightweight reference container for scene and game core objects.

SceneContext provides convenient access to scene-level and game-level core objects, as well as entity/archetype data from EntityManager. It is designed to be passed around the codebase and is cheap to copy (contains only references).

SceneContext replaces the previous LogicContext struct and moves from src/logic/ to src/scenes/ to better reflect its broader usage.

◆ world_mouse_position

sf::Vector2f& steamrot::SceneContext::world_mouse_position

World-space mouse position for the current tick.

Computed once per tick by GhostPositioningLogic via positioning::camera::MapToWorldCoords. World-space systems (ghost rendering, grimoire collision, piece placement) read this value; screen-space systems (UI collision) use mouse_position instead.

Coordinate contract: mouse_position (sf::Vector2i) — screen pixels — UI collision only world_mouse_position (sf::Vector2f) — world space — everything else
