void steamrot::logic::positioning::ui::ApplyMinMaxSizing ( sf::Vector2f & size,
const Style & element_style )

Clamp a size vector to the minimum and maximum sizes in a Style.

A zero component in minimum_size or maximum_size means that axis is unconstrained. Minimum is applied before maximum so that if both are non-zero and contradictory the maximum wins.

Parameters
sizeSize vector to clamp in-place
element_styleStyle whose minimum_size and maximum_size are used

Position all visible UI entities in the entity memory pool.

Iterates the provided entity indices, retrieves each entity's CUserInterface component, and calls PositionNestedUIElements for every visible entity that has a root element.

Parameters

scene_entitiesEntityMemoryPool containing CUserInterface components.
