Detailed Description

Engine resources struct containing global core objects.

EngineResources owns all engine-level global resources (window, event handler, asset manager, etc.). These resources have a lifetime matching the Engine instance.

All members are concrete objects (no references/pointers to other core members). This struct is default-constructible and should be configured via ConfigureEngineResources free function.
