void steamrot::logic::action::ghost::ClearGhostSelection ( MrGhost & mr_ghost)

Clear the current ghost instance on MrGhost.

Sets mr_ghost.m_instance to std::monostate, indicating no active selection. Callers are responsible for choosing this function when the relevant GhostPayload::GhostAction is CLEAR or NONE.

Parameters
mr_ghostMrGhost instance whose selection will be cleared.

MrGhost & mr_ghost,

Dispatch a single active GHOST subscriber to the correct action free function.

Guards against a missing or mis-typed captured payload, then switches on GhostPayload::GhostAction to call SelectGhostItem (SELECT) or ClearGhostSelection (CLEAR / NONE). Callers are responsible for checking that subscriber is active before passing it in.

Parameters
subscriberActive subscriber whose captured_payload holds the action.
mr_ghostMrGhost instance to mutate.
asset_managerAssetManager used to resolve a SELECT tag.

void steamrot::logic::action::ghost::SelectGhostItem ( MrGhost & mr_ghost,
const GhostSelection & selection,
AssetManager & asset_manager )

Resolve a GhostSelection tag to an instance and apply it to MrGhost.

Looks up the Fragment or Joint identified by selection in asset_manager, constructs the corresponding FragmentInstance or JointInstance, and stores it in mr_ghost.m_instance. If the tag cannot be resolved (e.g. GrimoireMachina is unavailable or the key is missing), mr_ghost is left unchanged.

Parameters
mr_ghostMrGhost instance to update.
selectionGhostSelection tag identifying the chosen item.
asset_managerAssetManager used to resolve the tag to a Part definition.
