◆ ClearGhostSelection()

void steamrot::logic::action::ghost::ClearGhostSelection ( MrGhost & mr_ghost)

Clear the current GhostSelection on MrGhost.

Sets mr_ghost.m_selection to std::monostate, indicating no active selection. Callers are responsible for choosing this function when the relevant GhostPayload::GhostAction is CLEAR or NONE.

Parameters
mr_ghostMrGhost instance whose selection will be cleared.

◆ ProcessSubscriber()

void steamrot::logic::action::ghost::ProcessSubscriber ( Subscriber & subscriber,
MrGhost & mr_ghost )

Dispatch a single active GHOST subscriber to the correct action free function.

Guards against a missing or mis-typed captured payload, then switches on GhostPayload::GhostAction to call SelectGhostItem (SELECT) or ClearGhostSelection (CLEAR / NONE). Callers are responsible for checking that subscriber is active before passing it in.

Parameters
subscriberActive subscriber whose captured_payload holds the action.
mr_ghostMrGhost instance to mutate.
