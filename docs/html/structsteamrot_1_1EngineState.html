Detailed Description

Engine runtime state.

EngineState contains runtime operational data that changes during engine execution. This includes execution control flags, subscriptions, and performance tracking. Unlike EngineConfig, this state is mutable and changes frequently during runtime.

EngineState can be configured from data (e.g., subscribers loaded from configuration files) and is also modified during execution.
