bool steamrot::SimulationData::use_default_logic {false}

When true, the TestEngine uses the scene's pre-built logic_map (as configured by LogicFactory) instead of the explicit steps list.

This exactly mirrors the production GameEngine behaviour: each scene runs sCollision, sAction, sMovement and sRender in the standard order using the Logic objects that LogicFactory created for that scene type. The steps list is ignored when this flag is set.
