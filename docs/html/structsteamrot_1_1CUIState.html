Detailed Description

Component for managing UI visibility based on scene state.

This component maps state keys to UI visibility states, specifying which UI components should be on and which should be off.

Mapping of state keys to their associated subscribers.

Each state key can have multiple subscribers. The state will only be set to true when ALL subscribers are activated (AND logic).

◆ m_state_to_ui_disabled

std::unordered_map<std::string, UIDisabledState> steamrot::CUIState::m_state_to_ui_disabled

Mapping of state keys to UI disabled states.

Each state key maps to a UIDisabledState that specifies which UI component root elements should be disabled (greyed out) and which should be enabled when the associated subscribers all fire.
