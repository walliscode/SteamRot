◆ Build()

ChainDescriptor steamrot::logic::descriptors::ChainDescriptorBuilder::Build ( std::string name = "")

Returns a ChainDescriptor containing the steps added to this builder.

The optional name is stamped on the descriptor and appears in ScopeBegin/ScopeEnd trace events. If omitted the descriptor is unnamed.

If an error occurs during validation of the steps, returns a string describing the error instead.

ChainDescriptorBuilder & steamrot::logic::descriptors::ChainDescriptorBuilder::WhileIsTrue ( NodeDescriptor nd)

Append a repeating predicate that matches zero or more consecutive nodes while nd holds.

Adds a ChainStepKind::WhileIsTrue step. The DFS walk consumes nodes satisfying nd until the first node that does not satisfy it, then passes that node to the subsequent step.
