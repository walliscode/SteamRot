Detailed Description

Struct containing all data needed for testing.

A single TestData struct holds all necessary information to run the TestEngine through a simulation cycle and then data to validate the results.

◆ initial_scene_type

std::optional<SceneType> steamrot::TestData::initial_scene_type {std::nullopt}

If set, the TestEngine loads this scene from default data instead of using starting_engine_snapshot.

When present (and not UNKNOWN), TestEngine::StartUp() calls SceneManager::AddSceneFromDefault() with this scene type, mirroring the behaviour of GameEngine. The starting_engine_snapshot is ignored.
