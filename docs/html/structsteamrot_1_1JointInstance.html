Detailed Description

A placed instance of a Joint on the MachinaFormScaffold.

Derives from PartInstance and adds Joint-specific runtime state. The sockets vector is sized to joint_ptr->socket_config.socket_count at construction, with all positions zero-initialised. Call initialize_joint_socket_positions() to populate the positions using the even-spread algorithm before the instance is rendered or hit-tested. World-space position of socket i is obtained via: transform.transformPoint(sockets[i].local_position)

std::vector<SocketData> steamrot::JointInstance::sockets

Per-socket data (local position + mutable state) for this Joint instance.

Sized at construction; positions are zero-initialised. Call initialize_joint_socket_positions() to populate positions via the even-spread algorithm. Positioning Logic may subsequently update sockets[i].local_position to reposition individual sockets (e.g. to apply socket ring rotation). Apply the instance's transform to sockets[i].local_position to obtain the world-space position of socket i.
