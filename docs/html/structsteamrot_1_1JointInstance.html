Detailed Description

A placed instance of a Joint on the MachinaFormScaffold.

Derives from PartInstance and adds Joint-specific runtime state. The sockets map is sized to joint_ptr->socket_config.socket_count at construction, with all positions zero-initialised. Call initialize_joint_socket_positions() to populate the positions using the even-spread algorithm before the instance is rendered or hit-tested. World-space position of socket id is obtained via: transform.transformPoint(sockets[id].local_position)
