Detailed Description

Non-owning view of a single entry in a PartMap.

instance points directly at the std::variant<JointInstance, FragmentInstance> stored in the PartMap. Use std::holds_alternative or std::visit on *instance to distinguish type without an additional cast layer.

The PartMap that owns the referenced variant must outlive this node.
