void steamrot::logic::render::grimoire_machina::DrawSocket ( sf::RenderTexture & texture,
sf::Vector2f world_pos,
const SocketState & socket_state )

Draw a single socket circle at the given world position.

Creates a circle shape on the fly, coloured based on the socket's hover state (hover_color when hovered, base_color otherwise), and draws it onto texture. Keeping the circle transient avoids stale cached positions.

Parameters
textureRenderTexture to draw on.
world_posWorld-space centre of the socket circle.
socket_stateRuntime state of the socket (hover, connection status).
