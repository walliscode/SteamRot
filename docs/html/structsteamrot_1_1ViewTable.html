Detailed Description

template<class T>
struct steamrot::ViewTable< T >

A fixed-size lookup table indexed by ViewDirection.

Provides both direct array access and a std::map-compatible interface (size, count, contains, insert_or_assign) so that only explicitly inserted entries are considered "populated".

TElement type stored per direction.
