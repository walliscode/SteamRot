Detailed Description

Builds a ChainDescriptor from an ordered list of NodeDescriptor steps matched against a DFS walk through the PartGraph.

Usage:

ChainDescriptor linear_3 =
ChainDescriptorBuilder{}
.StartWith(is_terminal)
.Then(is_serial)
.End(is_terminal);
