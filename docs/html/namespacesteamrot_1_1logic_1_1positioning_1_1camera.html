◆ apply_pan()

void steamrot::logic::positioning::camera::apply_pan ( CameraState & camera_state)

Apply the current pan state to the camera position.

Each tick that a pan direction flag is active in camera_state, the camera's world-space position is moved by CameraState::kPanSpeed units in that direction. Multiple flags may be active simultaneously (e.g. W+D for diagonal movement).

Parameters
camera_stateCamera state providing pan flags and position to mutate.

const sf::RenderTexture & texture )

Build a world-space view for the given render texture.

Returns a view centred on camera_state.m_position with the current zoom level applied. The world origin (0, 0) is visible at the screen centre when m_position is the default {0, 0}.

Parameters
camera_stateCamera state providing position and zoom level.
textureRender texture whose size is used to build the view.
Returns
sf::View representing the world-space camera view.

Convert a screen-space pixel position to world-space coordinates.

Applies the current world view to map the given screen-pixel position to its corresponding world-space floating-point position. This is the single authoritative screen-to-world conversion.

Parameters
camera_stateCamera state used to build the world view.
screen_posScreen-space pixel position (e.g. mouse cursor).
textureRender texture required for the coordinate mapping.
Returns
World-space position corresponding to screen_pos.
