Detailed Description

Base struct for Fragment and Joint, wrapping common data shared by both part types.

Contains the name and per-direction vertex arrays that every Part variant must have. Socket data is held by the concrete subtypes (Fragment stores explicit local positions; Joint stores a procedural SocketConfig).
