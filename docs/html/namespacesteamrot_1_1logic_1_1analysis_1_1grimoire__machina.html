◆ build_part_graph()

PartGraph steamrot::logic::analysis::grimoire_machina::build_part_graph ( const MachinaFormScaffold & scaffold)

Build a PartGraph from a MachinaFormScaffold.

Single O(N+E) pass: creates one PartNode per part (populating node_index_by_id), then creates one PartEdge per connection (pushing the edge index into both endpoint nodes' edge_indices). All nodes and edges hold non-owning pointers into scaffold, which must outlive the returned PartGraph.

Parameters
scaffoldSource scaffold to build the graph from.
Returns
PartGraph with one node per part, one edge per connection, and fully populated node_index_by_id and edge_indices.
