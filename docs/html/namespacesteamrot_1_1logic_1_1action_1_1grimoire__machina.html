◆ place_next_piece()

void steamrot::logic::action::grimoire_machina::place_next_piece ( MachinaFormScaffold & scaffold,
const MrGhost & mr_ghost )

Place the current ghost item onto the scaffold as the next piece, creating a Connection when both the ghost and the scaffold have sockets ready to connect.

Calls check_MrGhost_for_connection_readiness and check_PartMap_for_connection_readiness. If both return a value the ghost instance is copied into scaffold (with a new stable ID) and a Connection between the two ready sockets is created via create_connection and appended to scaffold.connections.

By convention connections are only between a FragmentInstance and a JointInstance. Does nothing if the ghost and the PartMap part have the same type (both Fragment or both Joint).

Does nothing if:

  • scaffold.parts is empty (use place_first_piece instead),
  • the ghost instance is monostate or its part pointer is null,
  • either readiness check returns std::nullopt, or
  • the ghost type and the ready PartMap part type are the same.
Parameters
scaffoldThe active MachinaFormScaffold to place the piece on.
mr_ghostCurrent ghost state carrying the instance and its transform.
