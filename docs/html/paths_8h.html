Detailed Description

Namespace-based path provider for data directory access.

Directory Structure:

  • data/
    • defaults/: Default configuration data (read-only)
    • user/: User-specific data and saves (read-write)
    • assets/: Game assets (fonts, images, etc.)

Usage: #include "paths.h" auto path = steamrot::paths::GetDataDirectory();
