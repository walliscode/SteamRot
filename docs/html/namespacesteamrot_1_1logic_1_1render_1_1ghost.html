Draw the ghost item at the position encoded in its instance transform.

Dispatches to draw_fragment_instance or draw_joint_instance depending on which alternative is active in mr_ghost.m_instance. Draws nothing when the instance is monostate (empty selection).

Parameters
textureRenderTexture to draw on.
mr_ghostMrGhost carrying the current instance (transform already updated by GhostPositioningLogic this tick).
