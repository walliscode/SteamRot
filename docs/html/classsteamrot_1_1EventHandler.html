void steamrot::EventHandler::ConvertSFMLEventsToEventPackets ( const std::vector< sf::Event > & sfml_events)

Convert a tick's SFML events into EventPackets and add them to the waiting-room event bus.

This wrapper makes the ordering of SFML-to-engine conversion very visible relative to other EventHandler operations. All conversion logic is delegated to SFMLEventConverter.

Parameters
sfml_eventsSFML events gathered this tick.

void steamrot::EventHandler::SetInputActionRegistry ( InputActionRegistry && registry)

Set the input-action registry on the SFMLEventConverter.

The registry is built externally (by IInputActionConfigProvider) and moved in via RAII. Must be called at startup before the first tick.

Parameters
registryPopulated InputActionRegistry to take ownership of.
