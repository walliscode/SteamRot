Detailed Description

Positioning logic that applies camera-based events to the camera state.

Subscribes to EventType::CAMERA via logic_config.json data-driven configuration. Each tick that a CAMERA event is active the subscriber captures the CameraPayload and applies its scroll delta to SceneContext::camera_state via positioning::camera::ApplyZoom.
